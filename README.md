# Codex Quota Widget

Application macOS de barre de menus qui affiche les quotas Codex ChatGPT.

## Fonctionnalités

- Affichage du quota disponible ou utilisé
- Sélection de la fenêtre 5 h ou hebdomadaire
- Rafraîchissement automatique

## Lancer

```sh
swift run
```

Pour créer l’app autonome :

```sh
./scripts/build-app.sh
```
